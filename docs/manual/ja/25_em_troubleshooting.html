第 25 章

電磁場解析で困ったとき

この章の内容

  1. 25.1 理由の見つけ方
  2. 25.2 どのスタディにも出るもの
  3. 25.3 静磁場
  4. 25.4 共振モード・ポート解析
  5. 25.5 静電場
  6. 25.6 電子銃
  7. 25.7 今の版でできないこと

この章では、電磁場解析で出るチェックの指摘・解析のエラーと、その対処を説明します。最後に、今の版でできないことをまとめます。CAD の困ったときは第 29 章にあります。

25.1 理由の見つけ方

  • 解析の前にリボンの［物理］タブ → ［チェック］パネル → ［チェック］を押すと、右の［チェック］に設定の誤り（エラー）と注意（警告）が出ます。行をクリックすると、当てはまる項目が開きます。

  • 解析が失敗したときは、下の［ジョブ］のログに理由が出ます。ログの全体は、ジョブのフォルダの log.txt にあります（第 16 章）。

  • 値を変えたのに結果が変わらないときは、プロパティ パネルの［適用］を押していないことがほとんどです。

25.2 どのスタディにも出るもの

共通の指摘と対処
メッセージ・症状原因と対処
チェック: 「… はこの種類のスタディでは使えません」静磁場の材料・条件（磁性体・コイルなど）を共振モードのスタディに入れた（または逆）。その項目を消すか、種類を直す
場が要素ごとに段になる・粗い見たい所のメッシュが粗い。全体の要素の大きさを小さくするか、ボディを置いて小さいメッシュの材料を割り当てる（第 16 章）
対称面で切った結果がおかしい形状か励振が、その面について対称でない。対称面を外して確かめる

25.3 静磁場

静磁場の指摘と対処
メッセージ・症状原因と対処
チェック: 「コイル … にボディがありません」コイルの条件にボディが入っていない。フォームの［ボディ］の一覧でチェックを入れて［適用］
チェック: 「コイル … に電流がありません」1 ターンの電流が 0。値を入れて［適用］（検出コイルにするなら、そのままでよい）
チェック: 「スタディにコイルがありません」コイルの条件が無いので、磁場は 0 になる
「入口と出口の面がつながっています。ループのコイルは軸のまわりに穴のある形にし…」ループのコイルの軸が、ボディの穴を通っていない（穴の無いボディ、軸の点・向きの誤り）。形状か軸を直す（第 19 章）
「端子付きのコイルの端子が磁束平行の面の上にありません」端子付きのコイルの端が、磁束平行の対称面に乗っていない（第 19 章）
「対称面 … の bc = auto を決められません」コイルの軸が平行でない・向きがそろわない・端子付きのコイルがある。対称面の境界を手で選ぶか、対称面を外す
チェック: 「材料 … の B-H の表に誤りがあります」表の行が読めない、H・B が増えていないなど。行を直して［適用］（第 18 章）
警告: 「非線形の反復が … 回で収束しませんでした」飽和の強い所でニュートン法が終わらなかった。解析の設定で反復の上限を増やす。B-H の表なら点の並びが滑らかか確かめる
チェック: 「コイル … のボディが解析から除外されています」コイルのボディの材料が（除外）になっている。領域で材料を選び直す

25.4 共振モード・ポート解析

共振モード・ポート解析の指摘と対処
メッセージ・症状原因と対処
共振モード: 加速モード（TM010）が見つからない対称面の壁の種類がモードの対称と合っていない（中央の面を磁気壁にしたなど。第 21 章）か、目安の周波数が高すぎる
共振モード: 「モードが見つかりませんでした」解析の設定の探す周波数の目安を、求めたいモードの近くの値にする
ポート解析: 「スタディにポートがありません」ポートの面を選んで［ポート］を押す（第 22 章）
ポート解析: 「… はカットオフより下です」（ログ）その周波数では、ポートのモードが伝わらない。範囲を上げるか、導波管を太くする
ポート解析: 「共振探索ができませんでした: 共振がスイープの端にある」範囲を共振の両側に広げる（共振モードのスタディで周波数の目安を求めておくとよい）
ポート解析: 「場を足せませんでした: … model.msh と result.h5 がありません」結果のフォルダのメッシュが無い（古い結果・消した結果）。解析をやり直す
ポート解析: U/P_inc の図に「S の群遅延の値が FEM の点と … % 違う（使わない）」周波数の点が共振の線幅より粗い、近いモードが重なっている、ポートがカットオフに近い、など。解いた点をつないだ線になる（値は正しい）。適応スイープなら点の数を増やす

25.5 静電場

静電場の指摘と対処
メッセージ・症状原因と対処
チェック: 「スタディに電極がありません。…」電極のボディを選んで［電極］を押し、電位を入れる（第 23 章）
チェック: 「電極 … にボディも面もありません」フォームの［ボディ］の一覧でチェックを入れるか、面を選んで［適用］
チェック: 「電極 … の電位を入れてください」［電位］が空。値を入れて［適用］（0 V なら 0 V）
チェック: 「電極 … と … の両方に入っているボディがあります」1 つのボディは 1 つの電極にだけ入れる
警告: 「電極が 1 つで接地が無いので、電位はどこも同じになります（電場は 0）。…」［解析の設定］で外面を接地にするか、電極（0 V の電極など）を足す
「電極 … と … が接しています（同じ節点があります）。…」違う電極のボディが触れている。つながった導体は 1 つの電極にまとめるか、形を離す
「電極 …（… V）が接地の面（外面・接地の対称面）に接しています。…」0 V でない電極が接地の面に触れている。電極を面から離すか、外面・対称面を電荷ゼロにする
「領域 … の電位が決まりません（電極にも接地にもつながっていない部分があります）。…」電極にも接地にもつながらないボディがある（解析領域を消したときに離れたボディなど）。電極を置くか、そのボディを（除外）にする
「電極 … に指定された面は、解析領域の外面になりません。…」面だけの電極が、空気や別のボディの中にある。面を外して、その導体のボディを電極にする
「電極 …: メッシュに面の群 … がありません。」面の電極の面が解析の外面にない（自動の空気の中の面）。ボディの電極にするか、解析領域を消して外面にする（第 23 章）
表面の最大電界がメッシュで大きく変わる鋭い角の電界は特異で、メッシュを細かくするほど大きくなる。角を丸め、そこのメッシュを細かくする

25.6 電子銃

電子銃のチェックとエラー
出たもの・症状原因と対処
チェック: 「放出面がありません。…」陰極の放出する面を選んで［放出面］を押す（第 24 章）
「放出面 …: 面が電極の上にありません。…」放出面の面を持つボディが電極になっていない。陰極のボディを電極にする
「放出面 …: 面の前に真空がありません。…」面が電極や誘電体に接している。真空に面した面を選ぶ
「対称面 …: 電子銃の対称面は電荷ゼロだけです。…」接地の対称面は使えない。電荷ゼロにするか、全体で解く
「対称面 … の上で、外部磁場が面に沿っています。…」ソレノイドなど、軸を含む面に沿う磁場は対称面で切れない（電子が回転する）。対称面を消して全体で解く（第 24 章）
「放出が一度も起きませんでした。…」陰極の前の電位が陰極より低い。陰極より電位の高い電極があるか、ウェーネルトの電位が負すぎないかを確かめる
注意: 「反復が … 回で収束しませんでした。…」［緩和係数］を小さくする（0.2、0.1）か、［反復の上限］を増やす。放出面の近くのメッシュが細かいほど小さな値が要る。注意の中の dρ だけが 1 % 前後で止まっていれば、ビームの通り道はほぼ落ち着いている
注意: 「電極 … の電流の …% が真空を通って閉じています。…」電極が導体で外面につながっていないか、放出面のメッシュが粗い。その近くの自己磁場が弱くなる。正確にするなら給電の棒をボディにして外面まで伸ばすか、放出面を細かくする（第 24 章）
「静磁場の結果がありません。…」磁場に選んだ静磁場のスタディを解く（ふつうは［実行］が先に解く）

25.7 今の版でできないこと

  • 永久磁石の材料

  • 座標面以外の向きの断面、3D の力線（今は断面の上だけ）、等値面

  • 対称面が本当に対称かの自動の確認

  • 共振モード・ポート解析の周期境界（多セルの一部だけを解く）、壁ごとに違う導電率、共振モードの位相のアニメーション（ポート解析はできます）

  • 静電場の浮いた電極・空間電荷・ボディの間の面の電極

  • 電子銃の温度制限の放出・電子の熱速度・二次電子・回転対称の周期モデル（第 24 章）
