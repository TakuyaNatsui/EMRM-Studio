# EMRM-Studio — CAD 付きの 3 次元電磁場解析ソフト（試用版）

[English](README.md)

EMRM-Studio（Electric, Magnetic, Resonant Mode）は、加速器のマグネット・電子銃・加速空洞を設計するための
Windows 用デスクトップアプリです。本格的なパラメトリック 3D CAD で形を作り、材料・コイル・境界条件を割り当てて、
**静磁場・共振モード・ポート解析（S パラメータ）** を同じ画面で計算できます。

計算は有限要素法です。静磁場は辺要素の磁気ベクトルポテンシャル、共振モードとポート解析は
**曲線四面体上の 2 次 Nédélec 要素** を使い、少ない要素数で高い精度が出ます。

このリポジトリは EMRM-Studio の **配布（ダウンロード）・問い合わせ（Issues）** の場所です。アプリのソースコードは
含みません。

> **試用版:** すべての機能を使えますが、解析できるメッシュの要素数（四面体の数）に上限があります
> （共振モード・ポート解析は **10,000**、静磁場は **30,000**）。[試用版の制限](#試用版の制限) を参照してください。

## できること

- **3D CAD**: 拘束と寸法つきのスケッチ、押し出し・回転・スイープ・ロフト、ブーリアン、フィレット・面取り、
  パターン・ミラー、パラメータ。STEP / IGES の取り込みと書き出し
- **スタディ**: 1 つのモデルに静磁場・共振モード・ポート解析のスタディをいくつでも作り、切り替えて使う
- **静磁場**: 鉄（線形・B-H 曲線による飽和）、コイル（電流の入口・出口のある導線、トーラス型、スケッチの輪郭に沿って
  巻くコイル）、対称面、磁力線・カラーマップ・2D 断面図・多極成分の展開
- **共振モード**: 共振周波数、電磁場、壁損失と誘電体損失による Q 値、R/Q・加速電圧・表面電流
- **ポート解析**: 導波管・同軸ポート、S パラメータ（振幅・位相）、適応スイープ、共振探索（f0・Qe・Q0・QL）、
  任意の周波数の場、Touchstone の書き出し
- **表示**: 断面・矢印・カラーマップ・磁力線・2D グラフ。結果はプロジェクトに保存して後から開ける
- 画面は日本語と英語。ユーザーマニュアル（HTML）を同梱（ヘルプ → ユーザーマニュアル、F1）

## ダウンロードと起動

1. [Releases](https://github.com/TakuyaNatsui/EMRM-Studio/releases) から `EMRM-Studio-<版>-trial-win64.zip` をダウンロードします。
2. （任意）`SHA256SUMS.txt` の値でファイルを確かめます:
   `certutil -hashfile EMRM-Studio-<版>-trial-win64.zip SHA256`
3. zip をローカルのフォルダ（例: `C:\EMRM-Studio`）に展開します。ファイル数が多いので、クラウドで同期される
   フォルダ（OneDrive、Dropbox など）は避けてください。
4. 展開したフォルダの `EMRM-Studio.exe` を実行します。`examples` フォルダの例題（`.emrm`）を **ファイル → 開く** で
   開くと、すぐに解析を試せます。

EXE にはまだ **コード署名がありません**。「Windows によって PC が保護されました」と出たら、配布元を確かめたうえで
**詳細情報** → **実行** を押してください。公開直後の EXE はウイルス対策ソフトに誤って検出されることがあります。
その場合は [Issues](https://github.com/TakuyaNatsui/EMRM-Studio/issues) でお知らせください。

版の確認: コマンドプロンプトで `EMRM-Studio.exe version`。

## 試用版の制限

| 解析 | 解析できるメッシュの要素数 |
|---|---|
| 共振モード解析・ポート解析 | 10,000 要素まで |
| 静磁場解析（空気の領域を含む） | 30,000 要素まで |

- 上限を超えるメッシュも生成と確認はでき、解析は計算を始める前にメッセージを出して止まります。メッシュの
  サイズを大きくして要素を減らしてください。電流分布のプレビューは制限しません。
- それ以外の機能（モデリング、メッシュの生成、結果の表示と書き出し）は製品版と同じです。
- 用途の制限はありません（業務・営利目的にも使えます）。
- 試用版の利用には [試用版使用許諾契約](EULA.ja.md)（[English](EULA.en.md)）が適用されます。
