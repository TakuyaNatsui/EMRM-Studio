B.2 マウス操作のプリセット

画面の移動・回転・ズームのマウス操作は、普段使っている CAD に合わせて 16 種類から選べます（第 2 章・第 17 章）。どのプリセットでも、左クリックは選択、右クリックはコンテキスト メニュー、ナビゲーション中の Esc は取り消しです。

SOLIDWORKS 風

中ドラッグでオービット、Ctrl＋中で画面移動、Shift＋中でズーム、ホイールはカーソル位置ズーム（前に回すと縮小）。mcad の既定（ADR-001）。

操作動作
左クリック選択
左ドラッグ範囲選択
右クリックコンテキストメニュー
中ドラッグオービット
Ctrl+中ドラッグ画面移動
Shift+中ドラッグズーム
Alt+中ドラッグロール
中クリック (要素の上)オービットの中心を設定
中クリック (空白)オービットの中心を設定
中ダブルクリック全体表示
右ドラッグマーキングメニュー
ホイールズーム（前に回すとズームアウト）

このプリセットで変わるキー: 全体表示 = F、ビュー面 = Ctrl+8

Inventor 風（既定）

中ドラッグで画面移動、Shift＋中でオービット、ホイールでズーム（前に回すと縮小）。F2・F3・F4 を押したまま左ドラッグで画面移動・ズーム・オービット。

Shift+中ドラッグオービット
中ダブルクリック全体表示
F4+左ドラッグオービット
F2+左ドラッグ画面移動
F3+左ドラッグズーム
ホイールズーム（前に回すとズームアウト）

このプリセットで変わるキー: 全体表示 = Home、前のビューを表示 = F5、ホーム ビュー = F6、フィレット = F、勾配 = D、平面 = ]、軸 = /、点 = .、中心点円 = C、テキスト = T

Fusion 風

Fusion の既定プリセット: 中ドラッグで画面移動、Shift＋中でオービット、ホイールまたは Ctrl＋Shift＋中でズーム、中ダブルクリックで全体表示。
